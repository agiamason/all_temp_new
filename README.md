# Quick Start  

## Data

Large data files are stored separately in the Hugging Face dataset:

https://huggingface.co/datasets/dodoro123/all-temp-new-data

This GitHub repository excludes `/data` from version control. See `DATA_MANIFEST.tsv`
for the full data file list and sizes.
   
## Installation  
   
### Install PyTorch  
To install PyTorch, please refer to the official [PyTorch installation guide](https://pytorch.org/get-started/locally/) and select the appropriate version based on your local machine configuration.  
   
### Install Other Dependencies  
To install the remaining dependencies, run the following command:  
```shell  
pip install -r requirements.txt  
```  
   
## Revisiting the Experiments for the Random Protocol Work  
You can view the preliminary results in the [sample discharging pattern notebook](/code/sample_discharging_pattern.ipynb).  
   
## Reproducing the Lifespan Prediction Task Results  
The early results can be found in the [RUL baseline notebook](/code/rul_baseline.ipynb). To reproduce these results locally, download the necessary data from the `/data` directory. Note that PyTorch is required to run RUL tasks, as the baseline includes Neural Network models. For efficiency, it is recommended to use a machine with a GPU. Reproducing all models in the baseline on a single V100 GPU takes approximately one hour.  
   
## Reproducing the "Knee Point" Task Results  
Preliminary results can be found in the [Knee point notebook](/code/knee_point.ipynb). To reproduce these results locally, download the necessary data from the `/data` directory.  
   
## Reproducing the XPS Task Results  
Early results are available in the [XPS model notebook](/code/xps_model.ipynb). To reproduce these results locally, download the necessary data from the `/data` directory. If you are interested in the clusters generated by XPS, refer to the [XPS generate cluster notebook](/code/xps_generate_cluster.ipynb).
